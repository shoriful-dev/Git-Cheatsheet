# GitDocs Hub 🚀

A premium, state-of-the-art documentation hub for Git commands, built with **Next.js 16**, **React 19**, and **TypeScript**. Designed for developers who want a beautiful, high-performance reference for Git workflows.

![Next.js 16](https://img.shields.io/badge/Next.js-16-black?style=for-the-badge&logo=next.js)
![React 19](https://img.shields.io/badge/React-19-blue?style=for-the-badge&logo=react)
![TypeScript](https://img.shields.io/badge/TypeScript-Full-blue?style=for-the-badge&logo=typescript)
![Performance](https://img.shields.io/badge/Performance-Optimized-success?style=for-the-badge)

## ✨ Features

- **Premium UI/UX**: Modern dark-mode aesthetic with glows, gradients, and fluid animations.
- **Advanced Search**: Instant, keyboard-friendly search (⌘K) with deferred rendering for maximum responsiveness.
- **Smart Navigation**: 
  - Interactive Sidebar with active section tracking.
  - Right-side Table of Contents (ToC) for deep linking.
  - Responsive Mobile Drawer.
- **Deep Content**: Over 60+ Git commands categorized into 10 workflows (Setup, Branching, Stashing, Remote, etc.).
- **Pro Tips & Warnings**: Hand-crafted callouts for better developer productivity and safety.

## ⚡ Performance Achievements

This project utilizes the latest cutting-edge features of the React ecosystem:
- **React Compiler**: Automatically eliminates redundant re-renders at the engine level.
- **Next.js 16 Cache**: Optimized server-side data delivery using the latest caching directives.
- **Smooth Interaction**: Uses `IntersectionObserver` for zero-lag scroll tracking on the sidebars.
- **Turbopack Stable**: Native build performance for near-instant cold starts and hot reloads.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Runtime**: [React 19](https://react.dev/)
- **Language**: 100% [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 🏗️ Build

To create a production build with optimized standalone output:

```bash
npm run build
```
